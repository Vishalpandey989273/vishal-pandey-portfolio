# Vishal Pandey - Developer Portfolio

A responsive React + TypeScript portfolio based on an open-source portfolio template.

## Personalize it
Edit:
- `src/components/Main.tsx` — name, role, GitHub and LinkedIn
- `src/components/Expertise.tsx` — skills
- `src/components/Timeline.tsx` — education and experience
- `src/components/Project.tsx` — projects and GitHub/demo links
- `src/components/Contact.tsx` — contact section
- `src/components/Footer.tsx` — footer links
- `public/profile.jpg` — your profile photo

## Run locally
```bash
npm install
npm start
```

Then open http://localhost:3000

## Build
```bash
npm run build
```

## GitHub Pages
Update the `homepage` in `package.json` with your actual GitHub Pages URL, then configure GitHub Pages for the repository.

## Important
Replace all placeholder GitHub/LinkedIn links and project links with your actual profiles and repositories before publishing.
